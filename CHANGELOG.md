# Changelog

## 1.0.0-beta.4

- Simplified and polished the main TargetCopy window.
- Added compact raid-marker selection for generated macros.
- Added optional **Custom Macro** mode for adding custom commands.
- Improved `Copy Name` and `Copy /target` quick actions.
- Reworked raid-marker handling for WoW Forever compatibility.

## 1.0.0-beta.3

- Added a dedicated `/tc debug` diagnostics panel.
- Added runtime information for client compatibility and troubleshooting.

## 1.0.0-beta.2

- Fixed the repository layout for release packaging.

## 1.0.0-beta.1

- Initial public beta.
- Added target-name and `/target` copying.
- Added target-specific macro creation and updates.
- Added raid-marker macro support.
- Added Quick Copy with configurable modes and key binding.
- Added an optional draggable floating button and basic settings.
